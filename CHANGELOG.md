# Changelog

## 1.0.0

First release.

- Nine-step workflow built on three questions (locator, lineage, ceiling), with Rapid,
  Standard and Systematic modes, an update path and an audit mode.
- `ledger.py`: one tool for the evidence ledger, with commands to start, check, compute
  certainty ceilings, find keystone lineages, produce and record a re-reading worksheet,
  trace claims, render tables and check a written report. 44 coded rules, each with an
  explanation.
- Ten reference files, report and brief templates, and a complete worked example.
- Four evaluation scenarios with planted traps, trigger queries, and 54 tests.
